Mini-projet 1 — Calculatrice

Description : La fonction calculer applique l’opération demandée. Les conditions choisissent l’opération ; les exceptions empêchent une division par zéro et signalent une saisie incorrecte.

def calculer(a, operateur, b):
    if operateur == "+": return a + b
    if operateur == "-": return a - b
    if operateur == "*": return a * b
    if operateur == "/":
        if b == 0: raise ZeroDivisionError("division par zéro")
        return a / b
    raise ValueError("opérateur inconnu")

try:
    a = float(input("Premier nombre : "))
    op = input("Opération (+, -, *, /) : ")
    b = float(input("Deuxième nombre : "))
    print("Résultat :", calculer(a, op, b))
except ValueError as erreur:
    print("Erreur :", erreur)
except ZeroDivisionError as erreur:
    print("Erreur :", erreur)

Explication

La fonction calculer applique l’opération demandée. Les conditions choisissent l’opération ; les exceptions empêchent une division par zéro et signalent une saisie incorrecte.

Mini-projet 2 — Jeu de devinettes

Description : random.randint choisit un entier entre 1 et 100. La boucle while continue tant que la réponse est fausse ; les comparaisons indiquent si la proposition est trop petite ou trop grande.

import random

secret = random.randint(1, 100)
essais = 0
print("Devinez le nombre entre 1 et 100.")
while True:
    try:
        proposition = int(input("Votre proposition : "))
        essais += 1
        if proposition < secret:
            print("Trop petit !")
        elif proposition > secret:
            print("Trop grand !")
        else:
            print(f"Bravo ! Trouvé en {essais} essai(s).")
            break
    except ValueError:
        print("Entrez un nombre entier.")

Explication

random.randint choisit un entier entre 1 et 100. La boucle while continue tant que la réponse est fausse ; les comparaisons indiquent si la proposition est trop petite ou trop grande.

Difficultés et solutions

Le test de démonstration utilise une graine aléatoire fixée pour reproduire le nombre 50 ; le jeu normal choisit un nombre différent à chaque lancement.

Mini-projet 3 — Gestionnaire de notes

Description : Le dictionnaire associe chaque matière à sa note. La fonction analyser_notes calcule la moyenne et repère les clés associées aux notes minimale et maximale.

def analyser_notes(notes):
    moyenne = sum(notes.values()) / len(notes)
    meilleure = max(notes, key=notes.get)
    moins_bonne = min(notes, key=notes.get)
    return moyenne, meilleure, moins_bonne

notes = {}
nombre = int(input("Nombre de matières : "))
for i in range(nombre):
    matiere = input(f"Matière {i + 1} : ")
    note = float(input(f"Note de {matiere} (/20) : "))
    if not 0 <= note <= 20:
        print("Note invalide : saisissez une valeur entre 0 et 20.")
        continue
    notes[matiere] = note

if notes:
    moyenne, meilleure, moins_bonne = analyser_notes(notes)
    print(f"Moyenne : {moyenne:.2f}/20")
    print(f"Meilleure note : {meilleure} ({notes[meilleure]}/20)")
    print(f"Note la plus faible : {moins_bonne} ({notes[moins_bonne]}/20)")
else:
    print("Aucune note valide.")

Explication

Le dictionnaire associe chaque matière à sa note. La fonction analyser_notes calcule la moyenne et repère les clés associées aux notes minimale et maximale.

Difficultés et solutions

J’ai testé deux matières avec les notes 16 et 18. Une saisie hors de l’intervalle 0–20 est refusée.
