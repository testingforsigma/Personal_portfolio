Prompt Engineering

Cas pratiques avant/après et bibliothèque de prompts réutilisables.

Les éléments d'un bon prompt

Un bon prompt précise le rôle, le contexte, la tâche, le format attendu, les contraintes et, si nécessaire, un exemple.

Rôle
Le point de vue demandé à l’IA, par exemple professeur de programmation.
Contexte
Le niveau, l’objectif et les informations utiles.
Tâche
Une action claire : expliquer, comparer, corriger ou résumer.
Format de sortie
Un tableau, une liste, une longueur ou une langue précise.
Contraintes
Les limites à respecter : niveau débutant, pas de jargon, ne pas inventer.
Exemples
Un exemple de résultat attendu pour guider la réponse.

Cas pratique 1 — Améliorer la demande de réalisation du portfolio

Contexte réel : la consigne du portfolio a d’abord été transmise sous forme d’une demande générale de création du site, puis précisée avec la liste détaillée des modules et des livrables.

ÉlémentExemple
Prompt initial (faible)« Fais-moi le site du portfolio. »
Résultat obtenuUne base de site peut être créée, mais la demande ne précise ni les pages, ni les contenus obligatoires, ni les éléments à ne pas modifier. Le résultat risque donc d’être incomplet.
Prompt amélioré« À partir du ZIP du portfolio, complète les pages Cybersécurité, Prompt Engineering, Python, C, Algorithmique, Systèmes d’exploitation et Architecture & électronique. Respecte les blocs demandés, conserve la page Création de contenu intacte, ajoute les sources, les codes et les schémas dans medias/, relie les images avec img, et actualise les statuts uniquement lorsque les pages sont terminées. N’invente pas mes captures personnelles. »
Résultat obtenuLa demande précise les pages concernées, les livrables attendus, les contraintes de conservation et la règle de transparence. Le site peut être modifié de manière ciblée et vérifiable.
AnalyseLe prompt amélioré donne le contexte (ZIP existant), la tâche (compléter les pages), le format (HTML, images, codes), les contraintes (ne pas toucher Création de contenu) et un critère de réussite (statuts cohérents). Il réduit les interprétations.

Cas pratique 2 — Demander une explication de pointeur en C

Contexte : comprendre la différence entre une variable, son adresse et la valeur stockée à cette adresse.

ÉlémentExemple
Prompt initial (faible)« Explique les pointeurs en C. »
Résultat obtenuUne explication générale qui peut contenir trop de vocabulaire technique et ne pas montrer clairement la différence entre & et *.
Prompt amélioré« Tu es un enseignant de programmation C pour un étudiant débutant. Explique les pointeurs très simplement, une notion à la fois. Utilise un exemple avec int x = 10 et int *p = &x. Montre ce que donnent x, &x, p et *p. Explique chaque ligne, puis pose une seule question de vérification. N’utilise pas de jargon sans le définir. »
Résultat obtenuL’explication devient progressive : x est la valeur, &x est son adresse, p contient cette adresse et *p permet d’accéder à la valeur pointée.
AnalyseLe rôle, le niveau, le format, l’exemple imposé et la limite « une question à la fin » rendent la réponse plus adaptée à l’apprentissage.

Cas pratique 3 — Comparaison de deux outils pour expliquer un pointeur C

Besoin identique : obtenir une explication accessible du code int x = 10; int *p = &x;, avec un exemple et une question de vérification.

Prompt commun à copier dans les deux outils :

Tu es un professeur de C pour débutant. Explique le code int x = 10; int *p = &x; en 120 mots maximum. Distingue la valeur, l’adresse, le pointeur et le déréférencement. Ajoute un mini-tableau indiquant ce que représentent x, &x, p et *p, puis termine par une question simple. Si tu n’es pas sûr d’une adresse mémoire concrète, n’en invente pas.
CritèreChatGPTClaude
Fonction annoncéeExplication, rédaction, raisonnement et aide au code ; peut aussi travailler avec des fichiers et images selon les fonctions disponibles.Explication, génération de texte et de code, analyse et traitement d’images selon les fonctions disponibles.
Points à comparer pendant le testExactitude de la distinction entre adresse et valeur ; respect de 120 mots ; clarté du tableau.Exactitude de la distinction entre adresse et valeur ; respect de 120 mots ; clarté du tableau.
Limite à vérifierVérifier les exemples C et ne pas prendre une adresse mémoire fictive pour une adresse réelle.Vérifier les exemples C et ne pas prendre une adresse mémoire fictive pour une adresse réelle.
ConclusionLa comparaison doit se faire avec le même prompt et la même version de code. Les documentations officielles décrivent les capacités générales, mais ne permettent pas de déclarer qu’un outil a donné une meilleure réponse sans exécuter le test. Résultat du test — ChatGPT

Réponse obtenue ici avec le prompt commun :

Explication : x est une variable qui contient la valeur 10. &x désigne l’adresse mémoire de x. Le pointeur p reçoit cette adresse. Enfin, *p signifie « la valeur située à l’adresse contenue dans p » : ici, 10.

ExpressionSignification
xLa valeur stockée : 10.
&xL’adresse mémoire de x.
pLe pointeur qui contient l’adresse de x.
*pLa valeur pointée : 10.

Question : si on écrit *p = 20;, quelle sera la valeur de x ?

Exemple illustratif de réponse possible avec Claude

Attention : le texte ci-dessous est un exemple pédagogique rédigé pour illustrer le type de réponse attendu. Ce n’est pas une sortie réellement obtenue depuis une session Claude et il ne doit pas être présenté comme une capture ou un test effectué.

La variable x contient le nombre 10. L’expression &x représente l’adresse mémoire de cette variable. Le pointeur p stocke cette adresse. L’expression *p permet d’accéder à la valeur située à cette adresse, donc à 10.

ExpressionSignification
xValeur : 10
&xAdresse de x
pPointeur contenant l’adresse de x
*pValeur située à cette adresse : 10

Question : si on modifie *p en lui affectant 20, quelle valeur contiendra x ?

Bibliothèque de prompts

Les modèles de prompts de cette page peuvent être réutilisés en remplaçant les éléments entre crochets.

Bibliothèque de prompts

  1. « Explique-moi [notion] comme à un débutant, avec une analogie et un exemple concret. Termine par une question. »
  2. « Tu es professeur de [matière]. Voici mon code : [code]. Ne donne pas la solution ; indique l’erreur et donne-moi un indice. »
  3. « Résume ce cours en une page : définitions, cinq idées à retenir et un exemple par idée. N’ajoute rien qui ne figure pas dans le texte. »
  4. « Pose-moi cinq QCM sur [chapitre], une question à la fois. Attends ma réponse avant de corriger. »
  5. « Compare [outil A] et [outil B] pour [besoin] selon la facilité, les limites, les fonctionnalités et les sources. »
