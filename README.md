## Comment publier ce site sur GitHub Pages

1. Crée un dépôt public sur GitHub nommé `portfolio-numerique`.
2. Mets tout le contenu de ce dossier à la racine du dépôt (fais un `git init`,
   `git add .`, `git commit -m "Site initial"`, puis `git push`), ou glisse-dépose
   les fichiers directement dans l'interface GitHub.
3. Va dans **Settings → Pages**, choisis la branche `main` (dossier `/root`), clique **Save**.
4. Après 1–2 minutes, ton site est en ligne à l'adresse indiquée par GitHub
   (généralement `https://ton-nom-utilisateur.github.io/portfolio-numerique/`).
